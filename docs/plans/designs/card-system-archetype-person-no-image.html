Card archetype 02 / degraded state

Ranbir Kapoor, without the portrait

Canvas skips any image that fails to load or would taint the capture canvas. Rather than leaving a hole, the recipe puts a fact row first: three tabular figures that carry the same “this is a real entity” weight the portrait did. The card is shorter (367 px vs 518) and still reads as finished.
